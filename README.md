# KFM Launcher

KFM Launcher is based on [Steam Achievement Manager](https://github.com/gibbed/SteamAchievementManager) (SAM). It was created to **save statistics**: the launcher buffers in-game stats and achievements while Killing Floor is running, then saves after `KillingFloor.exe` exits so session progress is not lost.

This application requires the [Steam client](https://store.steampowered.com/about/), a Steam account and network access. Steam must be running and the user must be logged in.

The original SAM is a lightweight, portable application used to manage achievements and statistics on Steam. Its closed-source version was originally released in 2008, last major release in 2011, and last updated in 2013 (a hotfix). The open-source SAM code is available so that those interested can do as they like with it.

The client protocol for sending stats and achievements to the launcher is described in [PROTOCOL.md](PROTOCOL.md).

[Download the latest KFM Launcher.exe](https://github.com/antonk777/KFMLauncher/releases/latest).
